# PRD — 반도체 시료 생산주문관리 시스템

> 상세 명세 원본: `docs/spec.pdf` (수업 자료인 관계로, 해당 repository에서는 생략)

## 배경 및 목적

가상의 반도체 회사 **S-Semi**는 다양한 종류의 반도체 시료(Sample)를 생산하여 연구소, 팹리스(Fabless) 업체, 대학 연구실 등 고객에게 납품한다.

기존에는 엑셀·메모장으로 주문을 관리하다 보니 주문량 급증 이후 다음 문제가 발생했다:
- 주문 처리 여부를 파악하기 어려움
- 공정 완료 예정 시각 불명확
- 재고가 충분한데도 불필요한 생산 공정이 가동됨

이를 해소하기 위해 **콘솔 기반 시료 생산주문관리 시스템**을 개발한다.

---

## 역할 및 흐름

```
고객                 주문 담당자              생산 담당자
 │                       │                       │
 │── 시료 요청(이메일) ──▶│                       │
 │                       │── 주문서 작성 ────────▶│
 │                       │                       │ 개발 시료 등록
 │                       │◀── 승인 / 거절 ────────│ 주문 수신 후 처리
```

- **고객**: 필요한 시료를 이메일로 요청
- **주문 담당자**: 요청에 맞게 주문서 작성, 주문 접수·목록 관리
- **생산 담당자**: 시료 등록, 주문 수신 후 승인 또는 거절

---

## 주문 상태 흐름

```
RESERVED   ← 주문 접수 (초기 상태)
    │
    ├── [거절] ──────────────────▶ REJECTED   (모니터링 제외)
    │
    └── [승인]
          │
          ├── 재고 충분 ──────────▶ CONFIRMED  (출고 대기)
          │                              │
          └── 재고 부족 ──────────▶ PRODUCING  (생산 중)
                                         │
                                    생산 완료
                                         │
                                    CONFIRMED  (출고 대기)
                                         │
                                    출고 처리
                                         │
                                    RELEASED   (출고 완료)
```

| 상태 | 의미 |
|------|------|
| `RESERVED` | 주문 접수 |
| `REJECTED` | 주문 거절 (정상 흐름 외, 모니터링 제외) |
| `PRODUCING` | 주문 승인 완료 + 재고 부족 → 생산 중 |
| `CONFIRMED` | 주문 승인 완료 + 출고 대기 중 |
| `RELEASED` | 출고 완료 |

## 기능 명세

### 1. 메인 메뉴

시작 시 전체 시스템 현황 요약과 기능 선택 메뉴를 표시한다.

**현황 요약 표시 항목**
- 현재 일시
- 등록 시료 수 / 총 재고
- 전체 주문 수 / 생산라인 대기 수

**메뉴 항목**

| 번호 | 메뉴 | 기능 |
|------|------|------|
| 1 | 시료 관리 | 시료 등록, 목록 조회, 이름 검색 |
| 2 | 시료 주문 | 고객 주문 접수 |
| 3 | 주문 승인/거절 | RESERVED 주문 목록 확인 후 승인·거절 |
| 4 | 모니터링 | 상태별 주문 수 + 시료별 재고 현황 |
| 5 | 생산라인 조회 | 현재 생산 중 + 대기 큐(FIFO) 확인 |
| 6 | 출고 처리 | CONFIRMED 주문 출고 실행 |
| 0 | 종료 | 프로그램 종료 |

---

### 2. 시료 관리

시료(Sample)는 시스템의 가장 기본 단위. 등록된 시료만 주문 가능.

#### 시료 속성

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | `string` | 시료 ID (예: `S-001`) |
| `name` | `string` | 시료명 (예: `실리콘 웨이퍼-8인치`) |
| `avgProductionTime` | `double` | 평균 생산시간 (min/ea) |
| `yield` | `double` | 수율 0.0~1.0 (정상 시료 수 / 총 생산 수, 예: 0.92) |
| `stock` | `int` | 현재 재고 수량 (ea) |

#### 하위 기능

| 기능 | 설명 |
|------|------|
| 시료 등록 | 새로운 시료를 시스템에 추가. 입력값: ID, 이름, 평균 생산시간, 수율 |
| 시료 조회 | 등록된 모든 시료 목록 + 현재 재고 수량 표시 |
| 시료 검색 | 이름 등 속성으로 특정 시료 검색 |

---

### 3. 시료 주문 (주문 접수)

고객 요청을 받아 주문 담당자가 주문을 생성한다.

- 생성 시 주문 상태는 `RESERVED`
- 주문번호는 `ORD-YYYYMMDD-NNNN` 형식으로 자동 생성

**입력 항목**

| 항목 | 설명 |
|------|------|
| 시료 ID | 등록된 시료의 ID |
| 고객명 | 주문 고객 이름 |
| 주문 수량 | 요청 수량 (ea) |

#### 주문 속성

| 필드 | 타입 | 설명 |
|------|------|------|
| `orderNumber` | `string` | 주문번호 (예: `ORD-20260416-0043`) |
| `sampleId` | `string` | 시료 ID |
| `customerName` | `string` | 고객명 |
| `quantity` | `int` | 주문 수량 |
| `status` | `OrderStatus` | 주문 상태 |
| `createdAt` | `string` | 접수 일시 (`YYYY-MM-DD HH:MM:SS`) |

---

### 4. 주문 승인/거절

`RESERVED` 상태 주문 목록을 확인하고 승인 또는 거절을 처리한다.

#### 주문 승인 흐름

```
승인 요청 (RESERVED 주문)
    ↓
가용 재고 계산: availableStock = max(0, stock - reservedQty)
    (* reservedQty = PRODUCING + CONFIRMED 주문 수량 합산 — 선점된 재고)
    ↓
가용 재고 확인: availableStock >= quantity ?
    ├── YES → 상태 = CONFIRMED  (재고 차감은 출고 시점에 수행)
    └── NO  → 부족분 = quantity - availableStock
              실 생산량 = ceil(부족분 / (수율 × 0.9))
              총 생산 시간 = 평균 생산시간 × 실 생산량 × 60.0 (초)
              생산 큐 등록 (FIFO)
              상태 = PRODUCING
```

#### 주문 거절

- 즉시 `REJECTED` 상태로 전환
- 재고 변경 없음

---

### 5. 모니터링

담당자가 현재 시스템 상태를 한눈에 파악할 수 있도록 구성한다.

#### 주문량 확인

- 상태별(`RESERVED` / `CONFIRMED` / `PRODUCING` / `RELEASED`) 주문 건수 표시
- `REJECTED`는 유효한 주문이 아니므로 제외

#### 재고량 확인

- 시료별 현재 재고 수량
- 주문 대비 재고 상태 표기:

| 상태 | 조건 |
|------|------|
| **여유** | `stock > 0` 이고 `stock >= 미출고 전체 수요` |
| **부족** | `stock > 0` 이지만 `stock < 미출고 전체 수요` |
| **고갈** | `stock == 0` |

미출고 전체 수요 = RESERVED + PRODUCING + CONFIRMED 주문 수량 합계 (해당 시료)

---

### 6. 생산라인

생산라인은 시료를 하나씩 처리하는 단일 설비 흐름이다. 주문이 들어온 시료에 대해서만 생산한다.

#### 생산량 계산

```
부족분     = 주문 수량 - 현재 재고
실 생산량   = ceil(부족분 / (수율 × 0.9))   ← 수율 오차 10% 여유분 반영
총 생산시간 = 평균 생산시간 × 실 생산량 (min)
```

예시: 부족분 170ea, 수율 0.92 → `ceil(170 / (0.92 × 0.9))` = `ceil(205.3)` = **206ea**

#### 생산 완료 처리

생산 완료는 운영자가 수동으로 트리거하지 않는다.
**재고를 확인하는 모든 화면 진입 시점마다** 프로그램이 현재 시간을 기준으로 완료 여부를 자동 점검하고 즉시 반영한다.
복수 작업이 동시에 완료 조건을 충족하면 FIFO 순서대로 모두 처리된다.

자동 점검 시점:
- 메인 메뉴 진입 시 (모든 화면 이동 전 공통 적용)
- 시료 관리 화면 진입 시
- 주문 승인/거절 화면 진입 시
- 생산라인 조회 화면 진입 시
- 모니터링 화면 진입 시

**점진적 재고 반영**: 생산이 완료되기 전에도, 경과 시간에 비례하여 생산된 수량만큼 재고가 점진적으로 증가한다.
(`producedSoFar = floor(경과시간 / 개당생산시간)`, 이미 반영된 수량은 `creditedQuantity`로 추적하여 중복 방지)

완료 처리 내용 (전체 실 생산량 생산 완료 시):
1. 주문 상태: `PRODUCING → CONFIRMED`
2. 재고 차감은 이 시점이 아닌 **출고 시점**에 수행

#### 생산 현황 표기

- 현재 생산 중인 시료 정보 (주문 정보, 진행 상황 등)
- 대기 중인 생산 큐 목록 (FIFO 순서)

#### 생산 작업(ProductionJob) 속성

| 필드 | 설명 |
|------|------|
| `orderNumber` | 연결된 주문번호 |
| `sampleId` | 생산할 시료 ID |
| `actualQuantity` | 실 생산량 (ea) |
| `totalDuration` | 총 생산 소요시간 (초, `avgProductionTime × actualQuantity × 60.0`) |
| `enqueuedAt` | 큐 등록 일시 |
| `startedAt` | 생산 시작 일시 (직전 작업 완료 시각 기준 순차 계산) |
| `creditedQuantity` | 재고에 이미 반영된 수량 (점진적 재고 반영 중복 방지용) |

---

### 7. 출고 처리

`CONFIRMED` 상태 주문에 대해 출고를 실행한다.

- 출고 대상: `CONFIRMED` 상태 주문 목록 표시
- 특정 주문 선택 후 출고 실행
- 처리 후 주문 상태: `CONFIRMED → RELEASED`

## 데이터 영속성

JSON 파일 방식. 프로그램 재시작 후에도 데이터 유지.

```
data/
├── samples.json    ← 시료 목록
├── orders.json     ← 전체 주문 목록
└── production.json ← 생산 큐 상태
```

### JSON 스키마

**samples.json**
```json
[
  {
    "id": "S-001",
    "name": "실리콘 웨이퍼-8인치",
    "avgProductionTime": 0.5,
    "yield": 0.92,
    "stock": 480
  }
]
```

**orders.json**
```json
[
  {
    "orderNumber": "ORD-20260416-0043",
    "sampleId": "S-003",
    "customerName": "삼성전자 파운드리",
    "quantity": 200,
    "status": "PRODUCING",
    "createdAt": "2026-04-16 09:32:15"
  }
]
```

**production.json**
```json
[
  {
    "orderId": "ORD-20260416-0043",
    "sampleId": "S-003",
    "shortage": 170,
    "actualProduction": 206,
    "totalTime": 165.0,
    "enqueuedAt": "2026-04-16 09:32:20"
  }
]
```
